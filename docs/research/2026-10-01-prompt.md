# Follow-up to the LEGO task research note

Thanks, the note was useful. We have taken two decisions from it: the build moves to a fixed board
on the table, and the step-state judge will not be a general VLM. One thing stays: the wearer talks
to a full-duplex realtime voice model (GPT-Live class) that owns the conversation; the judge is only
a sensor feeding it facts. Before going into details, we want to know what already exists that is
close to this shape. Published research is not required: GitHub proofs of concept, demos, blog
write-ups and small projects are all useful here. Four direction-level questions:

1. **Closest existing systems.** Projects, papers or demos (2023 onwards) that combine smart
   glasses or a head-mounted camera, a cloud realtime/full-duplex voice model, and some form of
   visual state tracking to guide a manual task step by step. How did they do the perception, and
   did they report anything about reliability or latency? Open source is a plus.
2. **Board-state detection for LEGO/Duplo from a camera.** Existing code or papers that read the
   state of bricks on a baseplate (which cell has which colour) from a single camera, ideally a
   moving head-mounted one: the CMU Gabriel LEGO assistant, DuploTrack, LEGO sorter and
   brick-recognition projects, anything newer. Did any of them work with standard LEGO rather than
   Duplo, and what camera distance / resolution did they need? Is the code available and in what
   state?
3. **QoE of realtime voice agents under network impairment.** Any study (academic or industry)
   that measured user experience of a full-duplex voice assistant, or a WebRTC voice+video AI
   pipeline, under injected latency, loss or bandwidth limits. Even partial results or methodology
   papers help.

4. **How people attach vision to realtime voice models.** The OpenAI Realtime / GPT-Live class
   models take audio but no video stream; still images can be pushed into the session as items,
   and the model can call tools. So every voice+vision project built on them has had to choose
   a harness shape: push a camera snapshot into the session on some trigger, run a separate
   vision model and feed its text verdicts into the voice model's context, let the voice model
   call a "look" tool, or something else. Survey what projects (GitHub, OpenAI cookbook/examples,
   LiveKit/Pipecat/Daily examples, Gemini Live equivalents) actually did, at what cadence, and
   what they report about it: did the voice model narrate the camera unprompted, stay coherent,
   or get confused? Any pattern that several independent projects converged on is what we want
   to know about.

Same output shape as before: sources with links, flag thin evidence, no need for a recommended
design this time.
